# Delta Summary (Since Previous Docs Baseline)
Date: 2026-02-14

## Firmware/Behavior Changes
- AP SSID changed to role-independent `lrs-<chipid>`.
- AP rename on TX/RX role change removed (prevents disconnect during role switch).
- DS18B20 support implemented with configurable pin/interval.
- Default DS18B20 pin aligned to `GPIO0`.
- DS18B20 local reading now transferred over LoRa and shown as remote telemetry.
- Status UI refactored into `LoRa`, `WiFi Station`, `Soft AP` sections.
- Header badges now show relay, LoRa signal, and WiFi state.
- Dry-contact input moved to Sensors visual (`OPEN`/`CLOSED`).
- WiFi status scan list excludes LRS SoftAP patterns (`lrs-<chipid>` and legacy suffix variants).
- iOS input zoom issue fixed by forcing 16px form-control fonts.
- MQTT guarded for control performance:
  - runs only when STA connected and enabled
  - short socket timeout (1s)
  - LoRa state machine ticked before MQTT
- MQTT publishes `last_updated` topic.
- WiFi status no longer performs periodic target-SSID scans in status handler.

## Protocol Changes
- Encrypted payload expanded from 4 bytes to 8 bytes.
- Added sensor-capable fields:
  - `temp_code`
  - `sensor_mask`
  - `sensor_digital0`
  - `sensor_analog0` (reserved)
- Compatibility impact: old/new packet firmware are not wire-compatible.

## Defaults/Settings
- Heartbeat default: 60s.
- ACK timeout default: 5s.
- AP SSID: `lrs-<chipid>`.
- MQTT default host: `venus.local`.

## Tooling Changes
- Post-upload sticker output updated for role-independent AP SSID.
- Factory provisioning output updated for role-independent AP SSID.
