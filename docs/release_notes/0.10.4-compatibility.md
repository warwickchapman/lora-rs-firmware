## Compatibility

- Compatibility revision: `1`
- Minimum Flasher version: `0.10.4`
- Scope: gateways and remotes running this release.
- Behaviour: direct flashing remains available. Once booted, a release firmware rejects normal Flasher commands from an older compatibility revision. Fleet locks only the incompatible device.
- Upgrade path: update Flasher, reconnect, then retry the command. There is no legacy compatibility mode in this pre-release line.
