# v0.9.1-beta Continuity

## Summary
v0.9.1-beta is a clean full release rebuilt from current mainline state, with release-process hardening and flasher/firmware delivery consistency as the primary focus since v0.8.0-beta.

## Highlights
- Rebuilt and republished the full firmware + flasher artifact set through the current deterministic release workflow.
- Hardened release-process behavior to reduce accidental drift between intended release tag/version and published assets.
- Improved packaging consistency across platforms, including clearer handling of local firmware-path edge cases in flasher workflows.
- Continued alignment of release documentation and automation so release notes and published outputs remain reproducible.
